# Tpot Keyboard

Tpot keyboard is a Unoffical and Non-Profitable App that makes a sounds when you type on your keyboard!

This App Uses [HaxeFlixel](https://haxeflixel.com) and [HaxeUI](https://haxeui.org)!

> [!CAUTION]
> This app is on Alpha!, Any Bugs Can be reported on Built in Issue Tab!

This app only Supports Windows x64, x32(x86) is not tested yet.
<br>
More Platform May be Soon to come!
